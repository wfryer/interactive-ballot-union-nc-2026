# Interactive Ballot: Union County, NC (Nov 3, 2026)

A single-page interactive version of one sample ballot (Union County, North Carolina, Precinct 032 Fairview Elem-B0056). Each candidate links to an official campaign site when one could be found, with clearly labeled government or third-party fallbacks (Branch Politics, BallotReady, Ballotpedia). Party colors, a "My pick" tracker, and a print-friendly cheat sheet are included.

Nonpartisan, experimental project by [Wes Fryer](https://ai.wesfryer.com). Picks are stored only in your browser. Links gathered October 15, 2026; please verify before voting.

Part of the [Interactive Ballot](https://interactiveballot.com) project.
